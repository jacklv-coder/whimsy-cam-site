隱私權政策

01不蒐集個人資料

奇想相機不會向開發者傳送任何個人資料。App 沒有帳號註冊、廣告、統計或分析 SDK、追蹤或社交功能，也不讀取位置資訊。可選的 App 內購買（奇想相機 Pro）由 Apple 處理付款，開發者收不到你的付款資訊；是否已購買只在手機上向 Apple 核對。

02相機與麥克風

相機和麥克風僅用於拍照、錄影，以及在錄影時收錄聲音。影像都在手機上處理，不會上傳。

03照片、影片與相簿權限

拍攝的照片、影片和貼紙儲存在 App 自己的本機儲存空間。使用「存相簿」時，App 要求的是「僅加入照片」權限，只會將作品寫入系統相簿，不會讀取你的相簿。

「匯入沖印」使用系統照片選擇器，App 只能取得你親自選取的照片或影片。

04貼紙去背

貼紙去背使用 iOS 內建的裝置端辨識功能，圖片不會離開手機。

05字體下載

為貼紙加入文字時，部分字體會由 iOS 視需要從 Apple 伺服器下載。這是系統功能：App 只提出字體名稱的請求，不會傳送你的文字或照片。

06分享與拷貝

只有你主動點選「分享」或「拷貝」時，作品才會交給你選擇的 App。

07刪除資料與備份

你可以在 App 中刪除單張作品，或刪除 App，清除所有本機資料。沒有伺服器端帳號需要刪除。依你的裝置設定，iCloud 或電腦備份可能包含 App 資料。

08兒童

App 不針對任何特定年齡蒐集資訊。

09本網站

本站託管於 GitHub Pages。GitHub 可能依其隱私權聲明處理存取紀錄，例如 IP 位址。本站沒有開發者設定的統計或廣告指令碼。

10聯絡我們

如有問題，請透過 GitHub Issues 聯絡。提交的 issue 會公開顯示，請勿在其中填寫個人資料。

11政策變更

本政策更新時，我們會一併修改本頁的生效日期。
