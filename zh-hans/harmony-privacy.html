奇想相机鸿蒙版隐私政策

奇想相机鸿蒙版是本机相机与贴纸工具。拍摄、滤镜、主体提取、文字编辑和作品保存均在你的设备上处理。App 没有账号、广告、内购、统计或分析 SDK，也没有向开发者服务器上传数据的功能。

版本 / 生效日期：2026 年 10 月 13 日
运营者：闾金涛（Jintao Lv）

01照片、视频、音频和文字

仅为拍摄、导入、滤镜处理、主体提取、加字、浏览和导出作品，在设备内处理你拍摄或主动选择的照片、视频、视频音轨和输入的贴纸文字，以及素材内的拍摄日期和方向。照片、声音或文字可能包含敏感个人信息，请谨慎拍摄、选择和分享。本应用不做人脸身份识别，不将素材上传给开发者。

02权限与拒绝授权

相机权限用于当前拍摄页的实时取景与拍照，进入后台或相册时释放相机。你可以在系统设置中撤回相机授权。照片导入使用系统选择器，仅访问你主动选中的内容；保存到系统相册由系统保存确认窗口授权，取消不影响原作品。本应用不申请麦克风、通讯录、定位、短信、电话或读取整个相册的权限。

03设备信息与加速度

为兼容本机媒体编码、适配布局、文字和日期显示，读取系统版本、屏幕尺寸与安全区域、语言和相关音效设置，以及相机和编码器能力。为摇一摇加速显影，仅在对应作品可见并处于前台时使用加速度传感器，页面不需要时停止监听。不读取广告标识符、IMEI、设备序列号、安装应用列表或位置。以上信息不上传，也不用于广告或行为分析。

04第三方共享与组件

本应用没有向第三方自动发送个人信息的功能，不出售个人信息。你主动点按“分享”并选择接收应用后，所选作品会通过系统分享服务交给该应用，后续处理适用接收方的规则；你可以取消分享。“复制”只将所选贴纸写入系统剪贴板，不读取剪贴板内容，其他应用在获得系统许可后可能读取你复制的内容。主体提取使用鸿蒙设备端视觉能力，图片在本机处理。OpenH264 组件仅用于本机视频编码，不收集信息或连接服务器。

05保存期限、安全与删除

作品和编辑偏好保存在应用沙箱中，保留至你删除作品、清除应用数据或卸载应用。删除单张作品会清理作品库内与其关联的文件。转换或导出的副本可能暂留在应用缓存目录，不随单张作品删除立即清理，之后可由系统回收；如需立即清除这类副本，可通过系统清除应用缓存（系统支持时）、清除全部应用数据或卸载应用。清除应用数据或卸载也会移除本机作品和偏好。应用使用系统沙箱保护本地文件。保存或分享出去的副本需要在对应相册或接收应用中另行删除。本应用不提供云同步；如果你启用系统备份，备份内容及保留方式由系统备份服务管理。

06查阅、复制和撤回同意

你可以在相册中查阅作品，通过保存或分享导出副本，或删除单张作品。在“设置 → 隐私政策”中可撤回同意；撤回后停止使用相机等能力并回到隐私说明，已有作品不因此删除。系统设置中可以单独撤回权限。我们没有服务器端账号或个人资料需要注销。隐私咨询、投诉和更正请求可通过下方 GitHub Issues 联系，我们将在 15 个工作日内受理并回复；Issues 是公开渠道，请勿填写照片、手机号或其他私人信息。

07未成年人

本应用不专为儿童设计。未成年人应在监护人指导下使用；不满 14 周岁的使用者应由监护人阅读本政策并同意。请勿在未经本人或监护人允许的情况下拍摄或分享他人个人信息。

08政策网站与更新

本政策在应用内提供离线副本。只有你主动选择“查看在线政策”或打开支持链接时，才会通过系统浏览器访问外部网站，App 不在后台发起该访问。官网由 GitHub Pages 托管，其服务方可能依照 GitHub 隐私声明处理访问日志，例如 IP 地址；网站没有开发者设置的广告或统计脚本。政策更新会修改版本和日期；若处理目的或范围发生实质变化，应用会在处理前重新征求同意。
